How It Works

Traefikr acts as an HTTP provider for Traefik, giving you a friendly interface while Traefik does what it does best - routing traffic.

⟷
Syncs via HTTP

You configure via the web UI. Traefik automatically picks up changes. Everyone's happy.

Get Started in 60 Seconds

One command. That's all it takes.

# Clone and start
git clone https://github.com/allfro/traefikr.git
cd traefikr
docker-compose up -d

# Get your admin password
docker-compose logs backend | grep "Initial Admin" -A 3

# Open http://localhost and start managing Traefik!

First startup creates an admin account with a secure random password. Save it and you're ready to go!
